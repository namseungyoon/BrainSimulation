## 2. 실험군 / 대조군 — 왜 두 번 돌리나

**TBS 앞뒤를 나눈 게 아니다.** 같은 실험을 처음부터 끝까지 **두 번** 돌린다. 각 런 안에 기저선 → TBS → 사후가 전부 들어 있다.

| | **실험군 (2단계)** | **대조군 (3단계)** |
| --- | --- | --- |
| 시냅스가 변할 수 있나 | **예** | **아니오** (`--freeze_rho` = γ_p·γ_d 둘 다 0) |
| 세포·시드·배선·자극 일정·mod | 동일 | 동일 |
| 재는 것 | 시냅스 강화 **+** 회로 반응 **+** 기저선 흔들림 | 회로 반응 **+** 기저선 흔들림 **만** |

TBS 뒤 기울기가 커지는 이유는 시냅스 강화 말고도 있다 — 억제세포 피로, 재귀 흥분 잔류, 기저선 표류.
대조군은 시냅스가 **물리적으로 못 변하는** 상태의 같은 실험이므로, 거기 나오는 변화는 전부 "시냅스가 아닌 이유"다.

> **실험군 − 대조군 = 순수한 시냅스 강화**

전규모에서 특히 중요하다 — 내부 연결이 서브셋 대비 **14배**이고, 대조군이 걸러내려는 게 정확히 그 부분이다.

## 3. 시냅스 모델 등록표 (`--syn_model`)

새 가소성 모델은 **mod 파일 하나 + `mea_experiment.py:69` 표에 한 줄**만 추가하면 같은 실험이 그대로 돈다.

| 이름 | mod 클래스 | 단기 | 장기 | 확률방출 | 역할 |
| --- | --- | --- | --- | --- | --- |
| `det` | `DetAMPANMDA` (BBP 표준 경로) | ✅ | ❌ | `--prob`따름 | **기준선** — 가소성이 없으니 변화는 전부 회로 효과 |
| `gb` | `GBPlasticitySyn` | ❌ | ✅ | ❌ | **모델 A** — 현재. 기존 결과와 연결됨 |
| `gbstp` | `GBPlasticityStpSyn` | ✅ | ✅ | ❌ | **모델 B** — TBS 버스트 내 촉진 포함 |
| `gbstpprob` | `GBPlasticityStpProbSyn` | ✅ | ✅ | ✅ | **모델 C** — 소포 단위 확률 방출(BBP MVR 이식) |

등록표 한 줄: `cls`(mod 클래스) · `stp`/`ltp`(단기·장기 유무) · `prob`(확률방출·setRNG 필요) ·
`rho`(가소성 상태변수 이름) · `freeze`(얼릴 파라미터) · `init`(초기값 파라미터) · `desc`.

설계 근거·우리 선택·검증은 → 모델 B `shared/mechanisms/GBPlasticityStpSyn.md` ·
모델 C `shared/mechanisms/GBPlasticityStpProbSyn.md`

⚠️ **모델 C 두 가지 주의.** ① 확률이라 **시드마다 결과가 다르다** — 비교는 시드 고정, 흔들림은 시드 스윕.
② `Nrrp=1`·`ca_stp=1`이면 방출 1회당 칼슘이 `1/Use = 6.67`로 강화 문턱(1.3)의 5.1배가 되어
성공한 방출이 거의 전부 강화로 간다. 이건 **우리 정규화가 만든 인공물**이지 결과가 아니다.
`--ca_stp 0`(칼슘을 Graupner 원본으로 고정)을 먼저 볼 것. 드라이버가 이 조합에 `[경고]`를 찍는다.

### 4단계 형태 예행 — `--rho_init` 주입이 실제로 먹는가 (32세포 · 3분)

4단계는 "2단계에서 나온 ρ를 60분 적분해 되꽂고 테스트 펄스만 쏘는" 런이다. 이 경로는 **한 번도 돌려본 적이
없었다** → 전규모 3.7 h를 태우기 전에 32세포로 형태만 확인했다(`--n_base 1 --tbs_bursts 0 --n_post 0
--t_settle 100`).

| 확인 | 결과 |
| --- | --- |
| 종료시각이 스케줄에서 나오는가 | 헤더·구동 둘 다 **160 ms**(= 100 + 60) · 청크 7조각. 예전 하드코딩 1000 ms였다면 전규모에서 **19.7 h 낭비** |
| 사후가 없을 때 LTP% | **NaN**. 예전 식은 `p_m=0` → **−100%**가 찍혀 "완전 소실"로 오독될 뻔했다 |
| ρ 주입이 finitialize 뒤에 살아남는가 | 파일 평균 0.6756 → 로그 `[ρ 주입] 평균 0.676` → **`ρ0 평균 0.676`** · ρ>0.5 **150개**(0.31로 심어둔 10개 정확히 제외) |
| `--freeze_rho`가 정말 얼리는가 | 구동 후 ρ 평균 0.676 · **Δ +0.000** |
| 주입한 ρ가 파형에 반영되는가 | 기저선 기울기 **−0.02302 → −0.04499 µV/ms** (ρ=0 대비 **×1.95**) · 두 런 모두 유발 스파이크 0 |

★ **fEPSP는 ρ에 선형이 아니다.** 효능식 `w = 1 + (b−1)ρ` (b = 5.28145)만 보면 ρ=0.676에서 **×3.89**가
나와야 하는데 실제는 **×1.95** — 절반이다. 스파이크가 0개였으므로 원인은 역치하 비선형(구동력 감소 ·
수상돌기 여과)이다. **함의**: 4단계에서 "ρ가 이만큼 남았으니 fEPSP도 이만큼 남는다"고 환산하면 안 되고,
**반드시 재측정 런의 값을 쓴다**(§5의 "60분 예측은 반만 공짜"가 수치로 확인된 셈).

## 5. 문제 3 — "지금 LTP는 굳지 않는다"

자극이 끝나면 칼슘 입력이 0이 되고 ρ는 이 식만 따른다.

```
τ · dρ/dt = −ρ(1−ρ)(0.5 − ρ)        (τ = 688,355 ms ≈ 11.5분)
```

**ρ > 0.5면 1로 올라가 굳고, ρ < 0.5면 0으로 내려가 사라진다.**
서브셋 결과는 ρ 평균 0.359, **0.5를 넘은 시냅스 0개**였다 → 몇 분이면 전부 0으로 돌아간다.
그때 본 +70.4%는 **자극 직후 반짝 상승**이지 문헌의 "1시간 뒤에도 남는 LTP"가 아니다.

### 시냅스 1개 예측기 — `shared/mechanisms/predict_tbs_rho.py`

전규모 런 1회가 98.9 h다. "TBS를 몇 버스트 줘야 ρ가 0.5를 넘는가"를 4일짜리 런으로 알아내면 안 된다.
TBS 구간에서는 **섬유 200/200이 전부 발화하므로 모든 SC 시냅스의 pre 입력이 네트워크와 동일**하다.
다른 것은 후시냅스 발화(C_post)뿐이라 0발 / TBS 펄스마다 1발로 **범위**를 잡았다.

| TBS 버스트 | 모델 A ρ (0발 ~ 1발) | 모델 B ρ (0발 ~ 1발) | 판정 |
| --- | --- | --- | --- |
| 3 (옛 서브셋 런) | 0.339 ~ 0.412 | 0.456 ~ 0.480 | 둘 다 **사라짐** |
| 5 | 0.481 ~ 0.563 | 0.603 ~ 0.623 | A 경계 · B 굳음 |
| 10 | 0.673 ~ 0.737 | 0.725 ~ 0.737 | 둘 다 굳음 |
| **15 (확정)** | **0.750 ~ 0.791** | **0.762 ~ 0.768** | 둘 다 **굳음(여유 있음)** |

**예측기 신뢰도** — 옛 2k 런(기저선 3 · TBS 3버스트 · 사후 4)의 **실측 ρ 평균 0.359**가
3버스트 범위 **0.339 ~ 0.412** 안에 들어온다.

**함의 2가지**
1. **TBS 15버스트 선택이 검증됐다.** 문제 3은 프로토콜 변경만으로 풀릴 전망이다(ρ 0.34 → 0.75).
2. **모델 B의 이득은 유도가 약할 때만 크다.** 3버스트에서 +0.10인데 **15버스트에서는 +0.01**로 줄어든다
   (둘 다 UP으로 포화). 칼슘 자체는 여전히 크게 다르다(c 최대 3.07 → 4.22 · θ_p 초과 929 → 1311 ms).
   → **201.2 h를 쓸 모델 B 트랙의 우선순위는 재검토 대상이다.**

### ★ "60분 뒤를 공짜로 예측"은 반만 맞다

| | 공짜인가 | 왜 |
| --- | --- | --- |

## 8. 실행 (WSL MPI 필수)

Windows conda NEURON은 MPI가 동작하지 않는다(`mpiexec -n 2`에서도 nhost=1). **WSL Ubuntu 사용.**
fEPSP는 세그먼트별 `i_membrane_`가 필요해 **CoreNEURON/GPU 미지원** → plain NEURON MPI.

```bash
bash _wsl_build_ltp_mods.sh          # 20종 + GBPlasticitySyn + GBPlasticityStpSyn → ~/mods_ltp (22 mod)
bash _wsl_stage.sh 1                 # 1단계 I-O          (모델 인자 생략 = gb = 모델 A)
IO_TEST=<1단계 결정값> bash _wsl_stage.sh 2      # 2단계 실험군
IO_TEST=<같은 값>      bash _wsl_stage.sh 3      # 3단계 대조군
bash _wsl_stage.sh 4                 # 4단계 60분 재측정 (2단계의 60분 ρ npz 필요)
```

런처가 고정하는 것: `--counts full --sc_g_pc 1.5 --rec_dt 0.4 --chunk 25 --ckpt_every 4` +
확정 프로토콜(`--n_base 5 --tbs_bursts 15 --n_post 10`). 진행·실패는 `figures/stage.log`에 누적된다.

**mod 적재 확인**(0단계 통과기준 ④) — 빌드 스크립트가 hoc 파일로 두 POINT_PROCESS를 실제로 생성해 본다.
⚠️ NEURON POINT_PROCESS는 **섹션이 `access` 된 상태**여야 만들어진다. 섹션 없이 `new GBPlasticitySyn(0.5)`만
하면 **이미 잘 쓰던 mod도 실패**한다(2026-08-06 오진 — 멀쩡한 mod를 LOAD FAIL로 잘못 읽었다).

## 10. 알려진 한계

1. **ETRI 실측 프로토콜 미문서화** — `14_realdata/` 분석 코드에서 역산한 것뿐(10 kHz · 자극 t=10 ms ·

   현 단계는 "특정 논문 재현"이 아니라 **문헌 규격에 맞춘 표준 슬라이스 LTP 실험**이다.

3. **자극 아티팩트 없음** — 실측에 있는 2 ms 블랭킹 구간이 시뮬에는 없다(파형이 깨끗함).
4. **60분 적분이 테스트 펄스 칼슘을 무시** — 실제 60분 동안은 30초마다 테스트 펄스가 칼슘을 조금씩 넣는다.
   우리 적분은 입력 0을 가정한다. 단일 테스트 펄스의 칼슘 피크가 약화 문턱(1.0) 부근이라
   **실제로는 예측보다 조금 더 내려갈 수 있다.**
5. **예측기는 시냅스 1개** — 억제·재귀흥분·세포별 편차·ρ↔발화 되먹임이 없다. 전규모 실측은 그 범위 근처여야 한다.
6. **실측 진폭 격차 미해결** — ETRI 실측 −40~−236µV vs 서브셋 시뮬 −1.24µV로 **30~200배**(모양·타이밍은 부합).
   SC 시냅스 수·섬유 수가 유력 후보이나 **실측 프로토콜을 받은 뒤** 다룬다.
