# 13_net_fepsp — 전체-네트워크 fEPSP · in silico MEA 실험

실제 in vitro MEA 샤퍼 곁가지 fEPSP 실험을 in silico로 재현하는 코드. **복제(순방향) 모델이 아니라
전세포의 실제 막전류**로 세포외 전위를 계산한다.

---

## ⚠️ 규모 표기 규칙 (필수)

**모든 결과·그림 캡션·보고에 규모를 명시한다.** 과거 서브셋 숫자를 규모 명시 없이 보고해 혼선이 있었다.

| 구분 | 세포 | 내부 연결(edge) | 내부 시냅스 접촉 | SC 시냅스 |
| --- | --- | --- | --- | --- |
| **전체 슬라이스**(배치 완료) | **17,647**<br>PC 15,723 + INT 1,924 | **6,438,379** | **28,233,245** | **1,020,340**<br>(E2c 기본 60/PC·40/INT) |
| **MEA 실험 서브셋**(E12에서 실제 실행) | **2,000**<br>PC 1,600 + PV 150 + cAC 150 + bAC 100 | **466,440** | — | **6,081** |
| 비율 | 11.3% | 7.2% | — | 0.60% |

- 서브셋을 쓰는 이유: **전규모 1회가 12~43시간**(실측 스케일링). 서브셋은 전극 주변 조밀 선택.
- SC 시냅스가 특히 적은 이유(0.60%): MEA 실험은 **자극전극 층대 200µm 내 수상돌기**에만 SC를 배선한다
  (국소 자극 = 실제 실험). 전체 슬라이스의 1,020,340은 **배경 포아송 구동**용 수치로 성격이 다르다.

## ⚠️ 시냅스 방출 모드 (정정 이력)

`mea_experiment.py`는 **기본이 결정론(deterministic, 룰베이스)** 이다. `--prob`을 주면 확률 방출(BBP EMS Random123).

| 실행 | 방출 모드 |
| --- | --- |
| E12 전체(I-O · PPF · LTP · 대조군 · 시드2) | **결정론 (det=True)** — 저장 npz 전수 확인 |

**정정(2026-08-05)**: 이전에 Notion·커밋·보고에서 이 실험들을 "확률 방출(Random123)"이라고 적었으나
**사실은 결정론**이었다. 원인 — 코드 109~110행에서 110행이 109행을 덮어써 기본값이 `det=True`가 되었고,
실행 시 `--prob`을 주지 않았다. 함께 정정할 것:
- I-O 시드 비교(결과 E)의 변동 원인은 확률 방출이 아니라 **시냅스 배치·섬유 배정 시드**다.
- 결정론에서도 시드는 (a) 내부 커넥톰 배치 (b) SC 시냅스 위치 (c) 섬유 배정을 바꾸므로 변동이 생긴다.

## 실험 구성 (모든 프로토콜 공통)

- MEA **3×8 = 24전극** · 간격 200µm · 지름 10µm · 24/24 조직 위
- **층 인식 기하**: 전극면 = CA1 층이 띠로 배열된 슬라이스 면 · z(유리면 거리) = **두께축**
  (층 좌표: SO −139 · SP 0 · SR +392 · SLM +791 µm)
- **자극전극 #4(SR층)** · 기록전극 **#3(SR, 자극에서 200µm)**
- **배경 포아송 SC 구동 없음** = 조용한 슬라이스. 유발 자극만 사용.
- SC 입력 = **촉진형 `SC->PC (E1s)`**(Use 0.15 · Dep 150 · Fac 250ms) — 단일시냅스 PPR 1.54 검증
- 자극세기 = **활성 SC 섬유 수**(전체 200개 중) — 생리적으로 자극 전류↑ = 동원 섬유↑

## 실행 (WSL MPI 필수)

Windows conda NEURON은 MPI가 동작하지 않는다(`mpiexec -n 2`에서도 nhost=1). **WSL Ubuntu 사용.**
fEPSP는 세그먼트별 `i_membrane_`가 필요해 **CoreNEURON/GPU 미지원** → plain NEURON MPI.

```bash
# 가소성 mod 포함 바이너리 사용(SPECIAL 오버라이드)
export SPECIAL=$HOME/mods_ltp/x86_64/special
bash _wsl_net_fepsp.sh 20 13_net_fepsp/mea_experiment.py \
     --counts 1600,150,150,100 --protocol ppf --ppf_isi 10,20,50,100,200 \
     --stim_t 100 --tstop 350 --rec_dt 0.4 --tag sub2k_ppf
```

## 알려진 한계

1. **LTP 고정(consolidation) 미검증** — ρ>0.5(쌍안정 UP) 0개. τ=688초라 장기 유지 확인엔 수분~시간 구동 필요.
2. **PPF와 LTP 동시 불가** — `GBPlasticitySyn`엔 단기가소성(Use/Dep/Fac)이 없다(모델 한계).
3. **짧은 ISI(10–20ms) PPR 측정 오염** — 1번째 응답 미회복 구간. scaled subtraction 보정 예정.
4. **전규모 미실행** — 서브셋 결과를 전규모로 외삽하지 않는다(규모 보정 실험 예정).
5. **실측 대조 보류** — ETRI 실측(fEPSP_E17/E45/E55)은 전체 데이터 미확보로 보류. 첫 확인 결과
   실측 진폭 −40~−236µV vs 서브셋 시뮬 −1.24µV로 **30~200배 격차**(모양·타이밍은 부합).
