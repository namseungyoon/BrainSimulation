# E2c-GPU 스파이크 분석 카탈로그 (전슬라이스 결정론 GPU 1초 런)

> 이 문서는 **전슬라이스 결정론 GPU 1초 런**의 산출물(스파이크 + 위치 + 커넥텀)에서
> **원리적으로 추출 가능한 모든 분석**을 카테고리별로 망라·정리한 카탈로그다.
> 각 항목은 **이름 / 필요 입력 / 상태**를 표로 정리했다.
> 상태 표기: ✅ = 이미 생성됨(그림 명시) · ⬜ = 원리적으로 가능·미생성 · 🔜 = 향후(추가 데이터/모델 필요).

---

## 0. 이 런과 데이터 소스

| 항목 | 값 |
|---|---|
| 규모 | 17,647 세포 (EXC 15,723 / INH 1,924) |
| 시간 | 1,000 ms (1초) |
| 시냅스 | 결정론(deterministic), SC(Schaffer collateral) 외부 입력 경로 |
| 하드웨어 | A6000 GPU (CoreNEURON, psolve 1.35h) |
| 요약 지표 | 스파이크 201,200 · 발화 99% · PC 12.37 Hz · INT 3.45 Hz |

**입력 파일**

| 파일 | 키/열 | 용도 |
|---|---|---|
| `sc_det_gpu/fullscale_n4/SC_spikes_all.csv` | `gid`(int), `type`(PC/INT), `t_ms`(float) · 201,200행 | 스파이크 (row[0]=gid, row[2]=t_ms) |
| `sc_det_gpu/fullscale_n4/SC_positions.npz` | `gid`(17647), `xyz`(17647,3), `type`(U3) | 런 출력 세포 위치 |
| `05_placement/slice_cells.npz` | `node_id`, `xyz`, `quat_wxyz`, `mtype`, `etype`, `layer`(SO/SP/SR/SLM), `sclass`(EXC/INH), `nd`(정규화 깊이) | 세포 메타 (gid=인덱스로 조인) |
| `07_connectivity/pruned_connectivity.npz` | `pre`, `post`, `cls`, `classes`(9경로), `n_syn` · 6,438,379 엣지 | 내부 커넥텀 |

**메타 분류 축 (조인 후 사용 가능)**
- **layer** (4): SP 17,330 · SO 264 · SLM 29 · SR 24
- **sclass** (2): EXC 15,723 · INH 1,924
- **mtype** (12): `SP_PC`, `SP_AA`, `SP_BS`, `SP_CCKBC`, `SP_Ivy`, `SP_PVBC`, `SO_BP`, `SO_BS`, `SO_OLM`, `SO_Tri`, `SR_SCA`, `SLM_PPA`
- **etype** (4): `cACpyr`(피라미드), `bAC`, `cAC`, `cNAC`
- **nd**: 정규화 깊이(연속) — 라미나 프로파일 축
- **xyz**: 3D 좌표 — 공간 지도/전파 축
- **9 내부 경로(cls/classes)**: `PC->PC (E2)`, `PC->SOM+ (E1)`, `PC->SOM- (E2)`, `PV+->PC (I2)`, `SOM+->PC (I2)`, `CCK+->PC (I3)`, `NOS+->PC (I3)`, `CCK+->CCK+ (I1)`, `CCK-->CCK- (I2)`

**기존 구현 스크립트**
- `e2c_gpu_perspectives.py` → **E2cGPU_overview.png / E2cGPU_raster.png / E2cGPU_compare.png** (이 GPU 런 전용)
- `gpu_result_numbers.py` → GPU 런 숫자 요약(그림 없음): 전체/층별/mtype별 발화율
- `e2c_full_perspectives.py` / `e2c_full_perspectives2.py` → CPU 확률판(E2cFULL_*). 같은 분석 로직이나 다른 데이터. **GPU판으로 재적용하면 즉시 산출 가능**한 항목이 다수.

## 부록 A. "즉시 재적용 가능" 우선순위 (CPU판 로직 → GPU 데이터)

CPU 확률판(`e2c_full_perspectives2.py`)에 **이미 구현된 로직**을 GPU 데이터 경로로 바꾸면 곧바로 산출되는 항목 (낮은 위험·높은 가치):

1. **깊이×시간 발화밀도 히트맵** (§2.6) — E2cFULL_dynamics (A)
2. **ISI-CV 분포** (§4.2) — E2cFULL_dynamics (B)
3. **Fano factor 집단 동기화** (§3.1) — E2cFULL_dynamics (C)
4. **내부 9경로 전달 활성** (§6.1) — E2cFULL_dynamics (D)
5. **세포별 발화율 공간지도** (§5.2) — E2cFULL_spatial

이들을 묶어 `E2cGPU_dynamics.png` + `E2cGPU_spatial.png` 로 생성하면 GPU 런의 분석 커버리지가 CPU판과 대등해진다. 파일명은 반드시 `E2cGPU_` 접두 사용(CPU판 `E2cFULL_*`와 분리).
