# PairSTDPSyn.mod — 고전 짝기반 STDP 시냅스 (04 자체 작성, 5-6)

> NMODL 은 ASCII 만 쓸 수 있어서 근거·선택·한계를 여기에 적는다. mod 를 고치면 이 문서도 고친다.

## 무엇인가

교과서에 나오는 **지수 STDP 창**을 NEURON 시냅스로 구현한 것이다.

```
dt = t_post - t_pre > 0  ->  dw = +A_p * exp(-dt/tau_p)     (pre→post = 강화)
dt < 0                   ->  dw = -A_d * exp(+dt/tau_d)     (post→pre = 약화)
dt = 0                   ->  0
```

구현은 **두 개의 감쇠 흔적(trace)** 으로 한다. 고립된 짝에서는 위 닫힌 형태와 정확히 같고,
트레인에서는 표준 all-to-all 합이 된다.

```
dx_pre /dt = -x_pre /tau_p        pre  스파이크: x_pre  += 1
dx_post/dt = -x_post/tau_d        post 스파이크: x_post += 1

pre  스파이크: w -= A_d * x_post   (직전까지의 모든 post 와의 짝)
post 스파이크: w += A_p * x_pre    (직전까지의 모든 pre  와의 짝)
```

## 왜 만드는가 — GB 계열의 **대조군**

Graupner-Brunel 계열은 내부에 **칼슘 상태**가 있어서 **같은 dt 라도 주파수와 이력에 따라
결과가 달라진다.** 고전 STDP 는 그런 상태가 없고 **스파이크 짝만** 본다.

5-1 에서 실측한 대비:

| | 같은 dt(+10ms) 를 반복할 때 |
|---|---|
| 고전 STDP | 창이 겹쳐 크기가 줄고 **50Hz 에서 부호가 뒤집힌다** (짝당 dw +0.551 → −0.118) |
| GB | 칼슘이 누적되어 **LTD 에서 LTP 로 전환한다** (theta_p 초과 1Hz 0ms → 50Hz 209.8ms) |

둘 다 주파수 의존적이지만 **기전이 다르다.** 6-3·6-4 가 그 차이를 실험으로 본다.
그 비교가 뜻을 가지려면 충실한 고전 STDP 가 있어야 하고, 그것이 이 mod 다.

## 전달은 GB 와 **구조를 똑같이** 맞췄다

```
A_AMPA += weight * w * factor_AMPA        (NMDA 는 x NMDA_ratio)
g = gmax*(B_AMPA-A_AMPA) + gmax*(B_NMDA-A_NMDA)*mggate
```

같은 이중지수 커널, 같은 Mg 게이트(Jahr & Stevens 1990), 같은 단위 규약
(`gmax` 는 µS, NetCon weight 는 전달 플래그 1.0 — D22 (1)).

**이유**: 5-10(엔진 간 첫 펄스 정합)은 엔진들이 **첫 펄스에서 같은 크기**여야 성립한다.
전달을 다르게 계산하면 "동역학 차이" 가 아니라 "크기 차이" 를 보게 된다.

## 가중치 범위를 GB 효능 축에 **의도적으로 맞췄다**

```
w in [w_min, w_max] = [1, 5.28145]  (기본)
rho = (w - w_min) / (w_max - w_min)
```

GB 의 전달 가중치는 `w = w0 + rho*(b*w0 - w0)` 이고 `w0=1`, `b=5.28145` 이므로
범위가 정확히 이것이다. **`w` 대신 `rho` 를 보고**하면 5-8·6-9 에서 두 엔진을 한 축에 놓을 수 있다.

경계는 **하드 클립**이다(고전 가산 규칙). 소프트·곱셈 경계는 **다른 모델**이므로 여기 넣지 않는다.

## 우리 선택 (Bi & Poo 1998 이 처방한 것이 아니다)

### 1. `all_to_all` (기본 1)

- `1` = 흔적이 누적된다(`x += 1`) → **모든** pre-post 짝이 기여
- `0` = 흔적을 덮어쓴다(`x = 1`) → **최근접 이웃**만 짝지어짐

두 규약은 약 20Hz 이상에서 크게 갈린다(창이 겹치기 시작한다). 5-1 의 주파수 실측이 그 경계를
보여준다. **어느 규약인지 반드시 명시**해야 한다 — 안 적으면 재현이 안 된다.

### 2. pre 스파이크에서의 순서

전달은 **그 스파이크 자신이 유발한 LTD 갱신 전의 `w`** 로 계산한다.

근거: 스파이크는 시냅스가 **현재 가진** 가중치로 전달되고, 그것이 유발한 가소성은 그 다음부터
효력을 갖는다. (반대 순서도 흔하다. 같은 순간의 차이라 최종 `w` 는 같고 그 스파이크의 전달
크기만 다르다.)

### 3. `A_p` / `A_d` 의 단위

`w` 의 **절대 증분**이다(범위의 비율이 아니다). 기본 범위 폭이 4.28145 이므로
`A_p = A_d = 0.1` 이면 완벽히 타이밍된 짝 하나가 전체 범위의 **2.3%** 를 움직인다.
5-10 이 이 값을 교정한다.

### 4. `tau_p` / `tau_d` 기본값 16.8 / 33.7 ms

**Bi & Poo 1998 로 널리 인용되지만 원문을 확보하지 못했다**(`docs/DECISIONS.md` 미결#14).
잠정값으로 취급하고, 원문을 구하면 이 문서와 mod 를 함께 고친다.

## 정확 검증 (5-6)

`w_min` 을 아주 낮게, `w_max` 를 아주 높게 두어 클리핑을 끄면 최종 `w` 는

```
w_init + (모든 짝에 대한 닫힌 형태 창의 합)
```

과 **정확히** 같아야 한다. 그러면 `lib/refs/stdp.py` 와의 차이는 **이벤트 시각 양자화**만
남는다. NEURON 고정 dt 는 이벤트를 dt 격자에 올리므로, 검증에서는 **스파이크 시각을 dt 의
정수배**로 둔다. 그 조건에서 실측 오차 < 1e-12.

## post 스파이크 경로

GB 계열과 동일하게 **weight<0 sentinel NetCon** 으로 받는다. 그래서
`lib/wiring.wire_post_sentinel()` 과 `lib/synprobe.drive_post()` 가 수정 없이 동작한다.

## ★ `INITIAL` 에서 `w` 를 초기화한다 — 의도적이다

GB 계열 mod 는 전달 가중치를 **BREAKPOINT 에서만** 계산하고 `INITIAL` 에서 초기화하지 않는다.
그래서 `t=0` 에 도착한 스파이크는 `w=0` 으로 전달되어 **오류 없이 사라진다**
(5-2 실측: t=0 전도도 0.0000 nS vs t=20ms 0.5968 nS · `docs/DECISIONS.md` D22 (2)).

이 mod 는 `INITIAL` 에서 `w = w_min + rho0*(w_max - w_min)` 을 설정하므로 그 함정이 없다.
그래도 자극은 `t>0` 에 두는 것이 좋다 — 다른 엔진과 조건을 같게 유지해야 비교가 된다.

## 없는 것 (일부러)

- **삼중항(triplet) STDP** (Pfister & Gerstner 2006) — 다른 모델이다. 필요하면 별도 mod.
- **전압·칼슘 의존성** — 그것이 GB·GluSynapse 의 몫이고, 이 mod 의 존재 이유는 그것이 **없는**
  대조군이 되는 것이다.
- **소프트 경계 / 곱셈 갱신** — 가중치 분포를 다르게 만드는 별개 모델.
- **확률 방출·단기가소성** — 필요하면 GB 계열처럼 합성판을 따로 만든다.
