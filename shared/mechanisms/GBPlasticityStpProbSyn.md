# GBPlasticityStpProbSyn.mod — 모델 C (확률방출 + 단기 + 장기)

> NMODL은 ASCII만 되므로 한글 설명은 이 파일에 둔다. mod 헤더의 영어 COMMENT와 같은 내용이다.

## 1. 무엇인가

모델 B(`GBPlasticityStpSyn`)에 **소포 단위 확률 방출**을 이식한 것이다. 새로 만든 물리는 없고, 이미 있는 세 mod의 블록을 합쳤다.

| 무엇 | 시간규모 | 출처 |
| --- | --- | --- |
| 장기가소성 — 효능 ρ | ~11.5분 | `GBPlasticitySyn.mod` (Graupner & Brunel 2012 PNAS) |
| 단기가소성 — 촉진 u | ~100 ms | `DetAMPANMDA.mod`의 TM 블록 (Fuhrmann 2002) |
| **확률 방출 — 소포** | 사건 단위 | `ProbAMPANMDA_EMS.mod`의 MVR 블록 (BBP · Random123) |

## 2. 모델 B와 무엇이 다른가

모델 B는 방출량을 **평균값** `Pr = u × R` 하나로 계산한다. 이건 여러 시행을 평균낸 값이다.

모델 C는 소포를 직접 센다. 방출자리가 `Nrrp`개 있고 각각 "차 있음/비어 있음" 둘 중 하나다. 프리 스파이크가 오면

- 비어 있던 자리는 각각 확률 `1 − exp(−Δt/Dep)`로 다시 채워지고,
- 차 있는 자리는 각각 확률 `u`로 방출한다.

방출된 소포 수를 `ves`라 하면 `ves/Nrrp`가 모델 B의 `Pr` 자리를 대신한다.

**여러 시행을 평균하면 둘은 같다.** 다른 건 한 번의 시행이다. `Nrrp`개가 전부 실패할 확률이 `(1−u)^Nrrp`인데, SC→PC (E1s) 값(`Use = 0.15`, `Nrrp = 1`)에서는 **펄스의 85%가 아무것도 방출하지 않는다.**

## 3. 방출 상태는 시냅스마다 하나 (NetCon마다가 아님)

`u` · `tsyn` · `occupied` · `unoccupied`는 `ASSIGNED`에 둔다(`ProbAMPANMDA_EMS`와 같은 방식). NET_RECEIVE 인자로 두지 않는다.

이 시냅스에는 NetCon이 정확히 두 개 붙는다 — 프리 섬유(weight > 0)와 후시냅스 스파이크 통보용(weight < 0). **후자는 방출 상태를 건드리면 안 된다.** 인자로 두면 NetCon마다 별도 사본이 생겨 뜻이 흐려진다.

## 4. 우리 선택 1 — 방출 정규화 (`norm_Pr`, 기본 켜짐)

`pr_ref = Use`로 나눈다.

쉰 시냅스에 첫 펄스가 오면 모든 자리가 차 있고 `u = Use`이므로 `E[ves/Nrrp] = Use`, 따라서 `E[prn] = 1`이다. 즉 **시행평균 기준 첫 펄스 크기가 모델 A·B와 정확히 같아진다.** 세 모델의 차이가 "크기"가 아니라 "동역학"만 남는다.

⚠️ **평균에서만 성립한다.** `Nrrp = 1`이면 한 시행에서 `prn`은 방출 성공 시 `1/Use = 6.67`, 실패 시 `0` 둘 중 하나다.

이 정규화는 **논문에 없는 우리 규약**이다. 끄면(`norm_Pr = 0`) 첫 펄스가 `Use`배(0.15배)로 작아지고, 1단계에서 정한 자극 세기를 재사용할 수 없게 된다.

## 5. 우리 선택 2 — 칼슘이 방출량을 따라가야 하는가 (`ca_stp`, 기본 켜짐)

```
C_pre_eff = C_pre × (1 + ca_stp × (prn − 1))     (음수면 0으로 자름)
```

| 값 | 뜻 |
| --- | --- |
| `ca_stp = 0` | 프리 스파이크마다 `C_pre` 고정. Graupner & Brunel 원본과 동일. 전달은 확률적이지만 칼슘은 아니다 |
| `ca_stp = 1` | 실제 방출을 따라간다. 실패하면 칼슘 0, 단일소포 성공하면 `1/Use = 6.67`배 |

### ⚠️ `Nrrp = 1` + `ca_stp = 1` 조합을 쓰기 전에 반드시 읽을 것

강화 문턱 `theta_p = 1.3`, `C_pre = 1.0`이다. 방출 한 번이 **6.67**을 주입하므로 문턱의 **5.1배**다. → **성공한 방출은 사실상 전부 강화로 간다.**

이건 발견이 아니라, **단일소포 방출을 "시행평균용 정규화"와 결합해서 생긴 우리 구성의 인공물**이다. `--ca_stp 0`을 먼저 돌려서 기준을 잡아야 한다. 드라이버가 이 조합을 만나면 헤더에 `[경고]`를 찍는다.

Graupner & Brunel 2012에는 방출 확률성이 아예 없다. 그러므로 **두 갈래 모두 논문 근거가 없고 우리 선택**이며, `ca_stp = 0`이 보수적인 쪽이다.

## 6. 지연 칼슘의 순서 문제 (모델 B와 같은 해법)

프리 스파이크의 칼슘은 `D = 18.8 ms` 뒤에 들어간다. 100 Hz 버스트의 펄스 간격은 10 ms라 항상 여러 사건이 공중에 떠 있다. 변수 하나에 담아두면 나중 스파이크가 앞 것을 덮어써 **틀린 칼슘이 들어간다.**

→ 양을 **self event의 flag에 실어 보낸다**: `net_send(D, 2 + C_pre_eff)`. 받는 쪽은 `flag >= 2`일 때 `c += (flag − 2)`. flag가 double이라 값이 그대로 살아남고, 사건마다 자기 몫을 들고 다닌다. 큐도 배열도 순서 가정도 필요 없다. 외부 NetCon 사건은 `flag == 0`이라 충돌하지 않는다.

## 7. 난수 — `setRNG`를 반드시 불러야 한다

`setRNG(s1, s2, s3)`으로 Random123 스트림을 심는다. `ProbAMPANMDA_EMS`와 동일하다.

**★ 안 부르면 `urand()`가 계속 0.0을 돌려준다.** 그러면 방출 판정(`result < u`)은 **항상 성공**하고 회복 판정(`result > Psurv`)은 **항상 실패**한다.

`Nrrp = 1`이면 결과가 이렇게 된다 — **첫 펄스에서 한 번 방출하고, 그 뒤로는 영원히 침묵한다.** 자리가 다시 안 채워지기 때문이다. "항상 방출"이 아니라 **죽은 시냅스**다. (`check_gb_mods.py` ⑦에서 100 Hz 버스트 4펄스 방출 소포 수가 `[1, 0, 0, 0]`으로 실측 확인)

에러가 안 나므로 **눈치채기 어렵다.** 그래서

- 드라이버(`mea_experiment.py`)가 시냅스를 만들 때 반드시 호출한다 (`SYN_MODELS`의 `prob=True`)
- 빌드 스크립트 `_wsl_build_ltp_mods.sh`의 로드 확인이 `setRNG(1,2,3)`까지 호출해 본다

`rng`는 `BBCOREPOINTER`가 아니라 평범한 `POINTER`다. 이 mod는 plain NEURON MPI 전용이고, CoreNEURON 스트림 직렬화는 의도적으로 지원하지 않는다.

## 8. 진단 변수

| 이름 | 뜻 |
| --- | --- |
| `pr_last` | 마지막 프리 스파이크의 `prn` |
| `ca_last` | 마지막으로 예약한 `C_pre_eff` |
| `ves_last` | 마지막 프리 스파이크에서 방출된 소포 수 |
| `n_pre` / `n_rel` | 누적 프리 스파이크 수 / 그중 방출이 일어난 수 |

**`n_rel / n_pre`가 길게 보면 `Use`에 가까워져야 한다.** 이게 확률 블록이 제대로 물렸는지 보는 가장 직접적인 검사다. 1.0에 붙어 있으면 `setRNG`를 안 부른 것이다.
