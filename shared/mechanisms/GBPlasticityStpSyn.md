# GBPlasticityStpSyn — 단기 + 장기 가소성 병합 시냅스 ("모델 B")

> NMODL은 ASCII만 읽습니다(한글을 넣으면 `Non-Ascii character in file` 로 컴파일 실패).
> 그래서 `GBPlasticityStpSyn.mod` 안 주석은 영문이고, 한글 설명은 이 문서에 둡니다.

## 1. 무엇을 합쳤나

새로 만든 물리는 없습니다. 이미 있던 두 mod를 그대로 가져다 붙였습니다.

| 무엇 | 시간 규모 | 어디서 왔나 | 원 논문 |
| --- | --- | --- | --- |
| 효능 ρ (장기) | ~11.5분 | `GBPlasticitySyn.mod` 전체 | Graupner & Brunel 2012 *PNAS* 109(10):3991 |
| 방출 Pr (단기) | ~100 ms | `DetAMPANMDA.mod` 의 TM 블록 | Fuhrmann et al. 2002 (결정론판) |

## 2. 왜 합치나

TBS 1버스트 = **100 Hz 4펄스**입니다. 실제 Schaffer collateral 시냅스는 이 10 ms 간격에서
**촉진**이 걸려(Fac = 250 ms) 2·3·4번째 펄스의 방출량이 첫 펄스보다 큽니다.

그런데 지금 쓰는 `GBPlasticitySyn`에는 **단기가소성이 아예 없습니다.** 네 펄스를 전부 같은
크기로 취급합니다. → **TBS가 실제로 만드는 칼슘을 과소평가**하고 있을 가능성이 있습니다.
이 mod는 그 가설을 검증하기 위한 것입니다.

실측(`check_gb_mods.py`) — 100 Hz 4펄스에서 정규화 방출량:

| 펄스 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| Pr_norm | 1.000 | **1.562** | **1.613** | **1.350** |

## 3. 결합 방식 — 곱셈

```
전달 진폭 = Pr_norm × w × (NetCon weight)
    w       = w0 + ρ(b·w0 − w0)      ← Graupner 원본 그대로 (장기)
    Pr      = u · R                  ← Fuhrmann/TM 원본 그대로 (단기)
    Pr_norm = Pr / pr_ref
```

## 4. ★ 우리 선택 2가지 (논문 근거 아님 — 반드시 명기)

### 선택 1 — Pr 정규화 (`norm_Pr`, 기본 켬)

`pr_ref = Use` 로 나눕니다. `Use`는 **충분히 쉰 시냅스의 첫 펄스 Pr** 입니다
(u0 = 0이면 첫 이벤트에서 u = Use, R = 1).

- **왜** — 이렇게 두면 쉰 상태의 첫 펄스가 모델 A와 **완전히 같은 크기**가 되고, 두 모델의
  차이가 오직 **버스트·연속자극 안의 동역학**만 남습니다. 비교가 성립합니다.
- **끄면** — 첫 펄스가 `Use`배(= 0.15배)로 작아집니다. 모델 A와 진폭 자체가 6.7배 달라져
  1단계(자극세기 결정) 결과를 재사용할 수 없게 됩니다.
- **논문에 있는 처방이 아니라, 모델 비교를 성립시키기 위한 우리 규약입니다.**

### 선택 2 — 칼슘도 방출량에 비례시킬 것인가 (`ca_stp`, 기본 켬 = 1)

```
C_pre_eff = C_pre × (1 + ca_stp × (Pr_norm − 1))
```

| `ca_stp` | 뜻 |
| --- | --- |
| 0 | 스파이크당 고정 `C_pre` — **Graupner & Brunel 원본 그대로.** 칼슘이 모델 A와 완전히 동일해집니다 |
| 1 (기본) | 방출이 촉진되면 글루탐산이 늘고 NMDA 칼슘 유입도 커진다는 해석 |

Graupner & Brunel 2012는 단기가소성이 없는 모델이라 `C_pre`를 상수로 두었습니다.
비례 가정은 **논문 결과가 아니라 우리 가설**입니다. `ca_stp = 0`으로 두면 정확히 원본으로
되돌아가므로 가설의 기여분을 직접 분리해 볼 수 있습니다 (검증 ④가 이것입니다).

## 5. 지연 칼슘의 순서 문제 — 그리고 처리

pre 스파이크의 칼슘은 **D = 18.8 ms 뒤에** 들어갑니다. 그런데 100 Hz 버스트의 펄스 간격은
**10 ms < D** 이므로 **대기 중인 이벤트가 항상 2개 이상 겹칩니다.**

`Pr`을 변수 하나에 담아두면 뒤 스파이크가 앞 스파이크 값을 덮어써서 **틀린 칼슘이
들어갑니다.** (스파이크1의 칼슘이 스파이크2의 값으로 주입됨)

**처리** — 값을 self-event의 **flag에 실어 보냅니다.**

```
보낼 때 : net_send(D, 2 + C_pre_eff)
받을 때 : if (flag >= 2) { c = c + (flag - 2) }
```

`flag`는 double이라 값이 그대로 보존되고, 이벤트마다 독립이라 순서가 섞이지 않습니다.
큐도 배열도 필요 없습니다. 외부 NetCon 이벤트는 `flag == 0`이므로 충돌하지 않습니다.

## 7. TBS 버스트 수에 따른 예측 — `predict_tbs_rho.py`

시냅스 1개로 확정 프로토콜을 미리 굴린 결과입니다. **TBS 구간에서는 섬유 200/200이 전부
발화하므로 모든 SC 시냅스의 pre 입력이 네트워크와 동일합니다.** 다른 것은 후시냅스 발화
(C_post)뿐이라 0발 / TBS 펄스마다 1발로 **범위**를 잡았습니다.

| TBS 버스트 | 모델 A ρ (0발 ~ 1발) | 모델 B ρ (0발 ~ 1발) | 판정 |
| --- | --- | --- | --- |
| 3 | 0.339 ~ 0.412 | 0.456 ~ 0.480 | 둘 다 **사라짐** |
| 5 | 0.481 ~ 0.563 | 0.603 ~ 0.623 | A 경계 · B 굳음 |
| 10 | 0.673 ~ 0.737 | 0.725 ~ 0.737 | 둘 다 굳음 |
| **15 (확정)** | **0.750 ~ 0.791** | **0.762 ~ 0.768** | 둘 다 **굳음(여유 있음)** |

**예측기 신뢰도** — 옛 2k 축소 네트워크 런(기저선 3 · TBS 3버스트 · 사후 4)의 **실측 ρ 평균
0.359**가 이 예측기의 3버스트 범위 **0.339 ~ 0.412** 안에 정확히 들어옵니다.

**한계** — 시냅스 1개입니다. 억제·재귀흥분·세포별 편차가 없고, ρ가 전달을 키우고 그 전달이
다시 후시냅스 발화를 바꾸는 되먹임이 없습니다. 전규모 실측은 이 범위 근처여야 합니다.

## 8. 이 결과가 계획에 주는 함의

- **TBS 15버스트 선택이 검증되었습니다.** 문제 3(지금 LTP는 굳지 않는다)은 프로토콜 변경
  만으로 해결될 전망입니다. 3버스트 → 15버스트가 ρ를 0.34 → 0.75로 올립니다.
- **모델 B의 이득은 유도가 약할 때 큽니다.** 3버스트에서 +0.10 (0.34 → 0.46)이지만
  15버스트에서는 +0.01 수준으로 줄어듭니다 — 둘 다 이미 UP으로 포화하기 때문입니다.
  칼슘 자체는 여전히 크게 다릅니다(c 최대 3.07 → 4.22, θ_p 초과 시간 929 → 1311 ms).
